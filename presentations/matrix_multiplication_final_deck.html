Research question

When does asymptotic theory become visible in real measurements?

The project compares five implementations that compute the same result, C = A x B, but organize the work differently.

Iterative

Three nested loops, direct baseline, Theta(n^3).

D&C

Eight recursive block products, still Theta(n^3).

Hybrid D&C

Recursive above a threshold, iterative below it.

Strassen

Seven recursive products, Theta(n^log2(7)).

Hybrid Strassen

Strassen at upper levels, iterative kernel at small sizes.

Block decomposition

Recursive algorithms change the organization of the work

Splitting matrices into four blocks creates smaller subproblems. The key question is how many recursive multiplications each level performs.

D&C: T(n) = 8T(n/2) + Theta(n^2)
Strassen: T(n) = 7T(n/2) + Theta(n^2)

Why Strassen helps

Saved multiplication compounds through recursion

Classical block product 8 calls

  • C11 = A11B11 + A12B21
  • C12 = A11B12 + A12B22
  • C21 = A21B11 + A22B21
  • C22 = A21B12 + A22B22

Four output blocks, two products each: 8 recursive multiplications of size n/2.

Strassen products 7 calls

  • M1 = (A11 + A22)(B11 + B22)
  • M2 = (A21 + A22)B11
  • M3 = A11(B12 - B22)
  • M4 = A22(B21 - B11)
  • M5 = (A11 + A12)B22
  • M6 = (A21 - A11)(B11 + B12)
  • M7 = (A12 - A22)(B21 + B22)

Then C11, C12, C21, and C22 are reconstructed from M1...M7. The added sums cost Theta(n^2); the saved recursive call changes the branching factor.

Hybrid idea

The threshold is the practical bridge between theory and hardware

Both hybrid algorithms use recursive structure only while subproblems are large. Once n <= 64, they switch to the iterative kernel.

What the threshold avoids

  • Recursive calls on tiny matrices
  • Temporary allocation overhead
  • Extra copying and recombination work

Theory versus practice

Same asymptotic class, very different behavior

Iterative, pure D&C, and Hybrid D&C are all Theta(n^3). Still, at 1024, pure D&C is much slower because its recursion creates allocation, copying, and recombination overhead.

Memory cost

At 1024 x 1024, Hybrid Strassen peaks at about 55.8 MiB of tracked heap, while the iterative baseline reports 0 B because it does not allocate temporary matrices through the tracker.

The smallest sizes are very short runs, so they are more sensitive to measurement noise. The larger sizes provide the most reliable interpretation of growth.

Main conclusions

The experimental story is about controlled overhead

  • Hybrid algorithms are the practical winners because they stop recursion before overhead dominates.
  • Pure Strassen demonstrates that a better exponent is not automatically a faster program.
  • Pure divide and conquer confirms that equal asymptotic complexity can hide large constant and memory costs.
  • Time, tracked heap, and numerical error must be interpreted together for a rigorous comparison.
