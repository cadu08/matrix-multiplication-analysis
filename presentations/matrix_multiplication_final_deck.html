Context and scope

Compared algorithms

All versions compute C = A x B. The difference is how the work is organized.

Iterative

Direct baseline. Three loops. O(n^3).

D&C

Eight recursive block products. O(n^3).

Hybrid D&C

D&C for large blocks. Iterative below n = 64.

Strassen

Seven recursive products. O(n^log2(7)), about O(n^2.81).

Hybrid Strassen

Strassen for large blocks. Iterative below n = 64.
Iterative: Cij = ∑k=1n AikBkj, for 1 ≤ i,j ≤ n
D&C: T(n) = 8T(n/2) + O(n^2)
Strassen: T(n) = 7T(n/2) + O(n^2)

Execution time

Mean execution time on a log scale

Observed growth

How fast does time grow when n doubles?

Example: if doubling n makes time about 8x larger, then log2(8) = 3, so the observed growth is cubic.

The estimate uses log2(T(2n) / T(n)). Strassen expects log2(7) ≈ 2.81. The expanded run will test whether that trend remains visible from 2048 through 16384.

Memory cost

Tracked heap peak by algorithm

1 MiB = 1,048,576 bytes ≈ 1.05 MB

At 1024 x 1024 in the collected baseline, Hybrid Strassen peaks at about 55.8 MiB of tracked heap. At 16384 x 16384, even one dense matrix of doubles needs about 2 GiB before recursive temporaries.

Correctness

Every aggregated group passed validation

Recursive algorithms change floating-point operation order, especially Strassen with extra additions and subtractions. The experiment therefore validates with absolute and relative tolerances instead of bitwise equality.

Main conclusions

The experimental story is about controlled overhead

  • Hybrid algorithms are the practical winners because they stop recursion before overhead dominates.
  • Pure Strassen demonstrates that a better exponent is not automatically a faster program.
  • Pure divide and conquer confirms that equal asymptotic complexity can hide large constant and memory costs.
  • Time, tracked heap, and numerical error must be interpreted together for a rigorous comparison.
